# Peer Review Feedback Template

Review two actual classmates' capstone drafts. Replace every placeholder with your own observations; do not invent URLs or results. Write **at least 150 words for each review**, then submit both completed reviews together as a single text response. Begin each review with something the project does well, cite specific elements or behaviors you observed, explain why they matter, and offer actionable improvements without unsupported assumptions. Use the [review checklist](review-checklist.md) while inspecting each project.
